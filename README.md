# ✈️ AI Travel Itinerary Generator

MERN stack application that generates AI-powered travel itineraries from uploaded travel documents.

## Live Demo
**Frontend:** https://travel-itinerary-ai-beta.vercel.app
**Backend API:** https://travel-itinerary-api.onrender.com/health

## Features
- ✅ JWT Authentication (Login/Register)
- ✅ Upload PDF/Image travel documents
- ✅ AI-powered text extraction
- ✅ Structured itinerary generation
- ✅ MongoDB database storage
- ✅ Itinerary history view
- ✅ Shareable links
- ✅ Drag-and-drop upload
- ✅ Responsive UI

## Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Auth:** JWT
- **Deployment:** Vercel + Render
